Setup Guide - SQL Query Demonstration Project

📋 Prerequisites

  • XAMPP installed (with Apache and MySQL)
  • Web browser (Chrome, Firefox, Edge, etc.)
  • Basic understanding of SQL

🚀 Setup Instructions

Step 1: Start XAMPP Services

  1. Open XAMPP Control Panel
  2. Click "Start" button for Apache
  3. Click "Start" button for MySQL
  4. Both should show green "Running" status

Step 2: Create Database

  1. Open your browser
  2. Navigate to: http://localhost/phpmyadmin
  3. Click "New" on the left sidebar
  4. Database name: football_tournament_db
  5. Collation: utf8mb4_general_ci
  6. Click "Create"

Step 3: Import Database Schema

  1. Click on the newly created database: football_tournament_db
  2. Click the "SQL" tab at the top
  3. Open the file setup.sql in a text editor
  4. Copy ALL the contents
  5. Paste into the SQL query box in phpMyAdmin
  6. Click "Go" button at the bottom right
  7. You should see a success message and tables created

Step 4: Verify Installation

After running the SQL script, you should see these tables:

  • Tournament (4 records)
  • Team (10 records)
  • Player (70 records)
  • Game (8 records)
  • Goal (15 records)
  • CleanSheet (3 records)
  • Ranking (6 records)
  • TournamentMatch (8 records)

Step 5: Access the Application

  1. Make sure Apache and MySQL are running
  2. Open your browser
  3. Navigate to: http://localhost/db_project/tournament_index.php
  4. You should see the main page with query buttons
Open Application →

🎯 How to Use

Running Queries

  1. Click any numbered button (1-15) to execute a predefined SQL query
  2. The SQL query will be displayed above the results
  3. Results are shown in a formatted table
  4. Each button demonstrates a different SQL concept

Custom Queries

  1. Scroll to button #16 "Custom SQL Query"
  2. Type your own SQL query in the text area
  3. Click "Execute" or press Ctrl+Enter
  4. Results will be displayed below

Example queries to try:

SELECT * FROM Team WHERE league_name = 'Premier League';
SELECT name, position FROM Player WHERE team_id = 2;
SELECT t1.name, t2.name, score_team1, score_team2 FROM Game g JOIN Team t1 ON g.team1_id = t1.team_id JOIN Team t2 ON g.team2_id = t2.team_id;

🛠️ Troubleshooting

Common Issues

❌ "Database connection failed"

  • Make sure MySQL is running in XAMPP
  • Check database name is exactly: football_tournament_db
  • Verify username is root and password is empty

❌ "Table doesn't exist"

  • Run the setup.sql script in phpMyAdmin
  • Make sure all tables were created successfully

❌ Blank page / 404 error

  • Check Apache is running in XAMPP
  • Verify URL is correct: http://localhost/db_project/tournament_index.php
  • Make sure files are in: C:\xampp\htdocs\db_project\

❌ Query errors

  • Check SQL syntax carefully
  • Verify table and column names are correct
  • Make sure to end queries with semicolon

📚 SQL Concepts Covered

  • SELECT - Retrieve data from tables
  • WHERE - Filter records based on conditions
  • JOIN - Combine data from multiple tables
  • COUNT, AVG, MAX, MIN - Aggregate functions
  • GROUP BY - Group rows with same values
  • HAVING - Filter grouped results
  • ORDER BY - Sort results
  • LIKE - Pattern matching
  • BETWEEN - Range queries
  • IN - Match multiple values
  • DISTINCT - Get unique values
  • UNION - Combine result sets
